# 지도 UI 명세

## 기본 레이어 순서

1. 저채도 배경지도
2. 행정구역 면
3. VIIRS 야간조도
4. Hansen 선택 기간 수목피복 손실
5. 결합 변화 핫스폿
6. 행정경계선
7. 시설물 클러스터와 개별 시설물
8. 선택 객체와 라벨

## 비교 모드

- 스와이프: 모바일과 일반 국민용 기본값
- 좌우 분할: 동일 중심·줌·회전 동기화
- 변화량: 비교연도에서 기준연도를 뺀 파생 레이어
- 타임라인: 0.5·1.0·1.5초/연도 재생, 다음 연도 사전 로드

## 줌 수준

- 5~7: 북한 전체와 시·도급 경계
- 8~9: 평양 구역·군 경계
- 10~11: 시설물 클러스터와 변화 핫스폿
- 12~13: 개별 시설물
- 14 이상: 시설물명·속성·분석 반경

## 시각화 규칙

- 야간조도 범례는 전체 분석기간의 고정 범위를 사용합니다.
- 팝업에는 변환 전 방사휘도와 단위를 표시합니다.
- 수목피복은 선택한 두 연도 사이의 신규 손실을 기본으로 표시합니다.
- 두 위성 래스터를 동시에 진하게 중첩하지 않습니다.
- 자료 없음, 관측 부족, 잠정치를 서로 다른 상태로 표시합니다.
- 지도와 동등한 표·차트를 제공하고 `prefers-reduced-motion`을 지원합니다.
