# 데이터 사전

## 실제 첨부파일 확인 결과

### 행정경계

- 형식: GeoJSON FeatureCollection
- Feature 수: 716
- 속성: admcd, cl, do, dong, gu, jic, mplis, nid, origin, rm, si, year
- 분석 적재 시 `admcd` 단위로 분리 Geometry를 병합합니다.

### 시설물 데이터

- 파일: `북한지도 시설물 데이터.xlsx`
- 시트: `시설물 데이터`
- 컬럼: 동향번호, 시설물번호, 시설물명, 카테고리, 주소, x좌표, y좌표
- `시설물번호`는 시설물 마스터 키로 사용합니다.
- `동향번호–시설물번호`는 다대다 연결로 분리합니다.
- `카테고리`는 `>`로 분할하되 원문도 보존합니다.
- X·Y는 원본 CRS 확인 전까지 Geometry로 변환하지 않습니다.

### 시설물 속성 데이터

- 파일: `북한지도 시설물 속성 데이터.xlsx`
- 시트: `시설물 속성 데이터`
- 컬럼: 시설물번호, 시설물명, 속성명, 속성값
- 동일 시설물·속성명에 여러 값이 있을 수 있으므로 유일 제약을 두지 않습니다.
- `Unnamed` 보조 컬럼으로 밀린 텍스트가 있으면 속성값 뒤에 복원하고 원본 행을 보존합니다.

### 전체동향

전체동향 원본은 배치 시 실제 시트와 컬럼을 먼저 검사합니다. ETL은 동향번호·제목·본문·게시일·분류·URL의 일반적인 별칭을 탐지하며, 매핑 실패 시 임의 적재하지 않고 오류를 반환합니다.
